# صفحة مقابلة مهندسة الذكاء الاصطناعي

صفحة عربية مستقلة تضم 40 سؤالًا وإجابات مرجعية، وتدوين إجابات المرشحة، وتقييمًا يدويًا من 0 إلى 4، وملخص النتائج. تعمل دون أدوات بناء أو مكتبات خارجية.

## تعليمات لكوديكس

المطلوب: نشر هذا المجلد على GitHub Pages وإرجاع رابط الصفحة الفعلي بعد التحقق من عمله.

1. استخدم حساب GitHub المصرح به. الحساب المتوقع AhmadFaour9؛ تحقق من الحساب المتاح قبل النشر.
2. أنشئ مستودعًا عامًا باسم ai-interview-ar إن كان متاحًا، أو اسمًا مشابهًا غير مستخدم. لا تستبدل مستودعًا موجودًا أو تمسح محتواه.
3. ارفع index.html و.nojekyll وهذا الملف إلى جذر الفرع main.
4. فعّل GitHub Pages للنشر من الفرع main والمجلد الجذر /.
5. انتظر اكتمال النشر، ثم افتح الرابط وتحقق من ظهور الأسئلة الأربعين، وإظهار الإجابات، وتدوين الملاحظات، والتقييم وحساب النتيجة، والفلاتر، والحفظ بعد التحديث، وإعادة ضبط الفلاتر عند بدء مقابلة جديدة.
6. افحص العرض بحجم شاشة iPad والهاتف. أعد رابط الموقع ورابط المستودع للمستخدم، ولا تكتفِ برابط ملف HTML داخل GitHub.

لا تحتاج الصفحة إلى مفتاح API أو خادم أو تثبيت حزم. إذا احتاج النشر إلى تسجيل دخول، اطلب من المستخدم إكماله دون طلب كلمة مروره أو رموزه في الدردشة.

## ملاحظات الاستخدام

- التقييم يدوي ويحسب الموقع مجموع الدرجات؛ لا يحلل الإجابات بالذكاء الاصطناعي.
- الأسئلة غير المقيّمة لا تدخل في النتيجة.
- الإجابات والملاحظات تحفظ محليًا في المتصفح، ولا تزامَن تلقائيًا بين الأجهزة.
- نقل المقابلة إلى جهاز آخر يتم بتنزيل نسخة احتياطية JSON واستعادتها هناك.
- نشر الملفات يجعل محتوى الأسئلة والإجابات المرجعية عامًا، ولا يرفع بيانات المقابلات المحفوظة في المتصفح.
- احتفظ بالموقع على مصدر مستقل؛ التخزين المحلي مشترك بين الصفحات على المصدر نفسه.
- يمكن الطباعة أو اختيار حفظ PDF من نافذة طباعة المتصفح.

## الملفات

- index.html: الصفحة الكاملة بتنسيق UTF-8 واتجاه من اليمين إلى اليسار.
- .nojekyll: للنشر المباشر دون معالجة Jekyll.
- README.md: دليل النشر والاستخدام.
